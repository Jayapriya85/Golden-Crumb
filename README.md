Golden Crumb🥐 - Bakery Landing Page

A modern, responsive, and visually appealing static landing page for a bakery. This project demonstrates a complete front-end development lifecycle, from AI-assisted UI prototyping to continuous cloud deployment.

**Live Demo:** [https://golden-crumb-nu.vercel.app](https://golden-crumb-nu.vercel.app)

🚀 Features
*   **Responsive UI:** Pixel-perfect layout optimized for both mobile and desktop screens.
*   **Modern Aesthetic:** Clean typography and a specialized color scheme designed specifically for bakery products.
*   **Fast Rendering:** Built with Vite for rapid local development and optimized production builds.
*   **Automated Deployment:** CI/CD pipeline configured through Vercel, triggering automatic deployments on Git pushes.

🛠️ Tech Stack
*   **Frontend Ecosystem:** React, TypeScript
*   **Styling:** Tailwind CSS
*   **Build Tool:** Vite
*   **Version Control:** Git & GitHub
*   **Cloud Hosting:** Vercel

⚙️ Development Workflow
1.  **Requirement & Prompt Engineering:** Analyzed a reference bakery UI using Claude AI to extract structural requirements and formulate precise technical prompts.
2.  **Rapid Prototyping (AI-Assisted):** Supplied prompts into Bolt AI to quickly scaffold the initial React component architecture and Tailwind CSS layout.
3.  **Manual Optimization:** Refactored the generated source code, removed redundancies, and fine-tuned specific utility classes to achieve the exact target design.
4.  **Cloud Deployment:** Tracked changes via Git, pushed the repository to GitHub, and connected it to Vercel for automated serverless deployment.

💻 Run Locally

To run this project on your local machine, execute the following commands:

1. Clone the repository:
   `git clone https://github.com/Jayapriya85/Golden-Crumb.git`

2. Navigate to the project directory:
   `cd Golden-Crumb`

3. Install dependencies:
   `npm install`

4. Start the development server:
   `npm run dev`
